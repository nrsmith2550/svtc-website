Owner Login Setup

Do this once (and again whenever the access key expires or you want to change the password). Everything happens in this browser; the key and password are never sent anywhere except the encrypted key, which is saved to the website.

  1. Create a GitHub access key: open GitHub →
    Name it Silent Victory site admin. Under Repository access choose Only select repositories → svtc-website. Under Permissions → Repository permissions set Contents to Read and write. Then click Generate token and copy it.
  2. Paste it below, choose the owner's username and password, and click Save Login.

Use at least 10 characters. A longer password (like a short phrase) keeps the login safer.
